# FLOWGUARD — спецификация и циклы внешнего ревью

Репозиторий документов: продукт, обе технические ветки, экономика, доктрина
цены, реестры утверждений для критики и результаты циклов внешнего ревью.

## Что читать первым

| Файл | Роль |
|---|---|
| `docs/FLOWGUARD-MASTER-v2.md` | **актуальный мастер-документ** для внешнего ревью (кидать в модели целиком) |
| `docs/FLOWGUARD-MASTER.md` | v1, первая версия — сохранена для сравнения |
| `docs/SPEC-v0.1.md` | деталь on-chain ветки (escrow, инварианты, атаки, приёмка) |
| `docs/SPEC-v0.2-LEGACY.md` | деталь legacy ветки (Z, медиатор, триггер, witness, оракулы) |
| `docs/SPEC-CRITIQUE.md` | расширенный реестр утверждений (~95) для гранулярной критики |
| `docs/80-PRICING-DOCTRINE.md` | доктрина цены: снижать цену и качество одновременно |

## Правило репозитория

Ни одно число, помеченное `[Г]` (гипотеза), не попадает в коммерческий
материал до закрытия соответствующего измерения `M`.

## Статус

Проектная спецификация. Не является обещанием безопасности.
