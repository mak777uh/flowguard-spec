# Cases — what was checked, what proves it, and what it does not

A case is the unit a stranger can produce without reading our source. It exists because the machine gate for
`P1` asked for a marker line in a card and a JSON record, and a person outside this repository could not know
that from the documents alone.

## The rule that makes a case a case

**One plain sentence first.** If a reader stops after the first line, they still know what was checked.

**Five sections, always the same order.** `Claim`, `Evidence`, `Reproduce`, `Verdict`, `Limits`. A case missing
one of them is not shorter, it is unfinished.

**Every claim needs a public link, a transaction hash, or a pinned commit.** Otherwise it is an opinion.

**"Not confirmed" counts the same as "confirmed".** Both are published; `could not tell` is a third legitimate
result, not a failure to try.

## How a case is laid out

```
cases/NNN-slug/
├── README.md   # the five sections; the first line after the title is the sentence
└── ...         # optional artifacts: logs, transcripts, JSON, screenshots
```

`NNN` is a number, `slug` is lowercase words separated by dashes. A case folder that does not follow the pattern
is refused by `lab/check-cases.py`, together with a missing section and a verdict outside the three allowed
words.

## The three verdicts

| verdict | means |
|---|---|
| `confirmed` | what was claimed happened, and the evidence shows it |
| `not confirmed` | it did not, or it did and the claim was wrong — say which |
| `could not tell` | the attempt did not reach an answer, and here is why that is not "no effect" |

## What a case is not

- Not a claim about our tool being correct. A case confirms a run, not a product.
- Not the P1 condition by itself. P1 needs a party who did not write the code; a case written by the author is
  an example of the format, and it says so in `Limits`.
- Not a place to argue. If a case needs three paragraphs of defence before the evidence, the evidence is missing.

## Registry

`cases/REGISTRY.md` is generated by `lab/build-case-registry.py` from the folders; `--check` fails when it is
stale. Do not edit it by hand.
