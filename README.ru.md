# FlowGuard — спецификация продукта и циклы внешнего ревью

> Русское зеркало [README.md](README.md). Канонический текст — английский; при расхождении верен он.

**Что это.** Документы одного продукта: сервис, который доказывает не «система безопасна», а
«в объявленном замыкании мимо единственной точки контроля пройти нельзя» — и выдаёт утверждение,
которое можно проверить, не доверяя его издателю.

**Чего здесь нет.** Обещания безопасности. Вне объявленного замыкания гарантия не действует,
и это записано в самом артефакте, а не в мелком шрифте.

## Политика открытости

Всё публикуется открыто по умолчанию — включая экономику, потолки маржи и внутренние оценки сроков,
потому что доверие проверяется, а не декларируется. Исключение ровно одно: **секреты**.

Это не лозунг, а механизм: в репозитории стоит страж, который блокирует публикацию при обнаружении
токенов, ключей, приватных ключей и локальных путей — в файлах **и во всей истории**.

```bash
bash lab/check-secrets.sh    # токены, ключи, локальные пути: файлы + история
python lab/check-links.py    # каждая относительная ссылка между документами существует
```

Оба гоняются автоматически на каждый push и pull request (`.github/workflows/guards.yml`).
Если кто-то однажды закоммитит токен, красным станет CI, а не репутация.

## Правило, которое не обсуждается

Ни одно число, помеченное как гипотеза, не попадает в коммерческий материал до закрытия
соответствующего измерения. Типы свидетельств и разрешённые формулировки — в [docs/CLAIMS.md](docs/CLAIMS.md):
три слова (`PROVEN`, `ENFORCED_TESTED`, `guarantee`) допустимы только при типе `proof` или `test`.
