## The finding: the two halves are complementary, not competing

This is the useful part. The kit is not a standard that both projects must converge on — it splits cleanly along
what each repository has already proven it can do:

- **VecDHT is strong on evidence production** — 227 experiment cards with pre-registered thresholds, a metrics
  file whose numbers carry their commands, and a status document written to be falsified. That is the machinery
  of *making* a result.
- **This repository is strong on evidence discipline** — a typed claim registry where the evidence type fixes the
  permitted wording, an elimination ledger with revival conditions, and three guards including a claim linter.
  That is the machinery of *speaking about* a result.

Neither project is missing a habit. Each is missing the other's.

## What each side should take, if the owner agrees

| Direction | Item | Why it is cheap on our side |
|---|---|---|
| VecDHT → here | **M1** experiment cards | the format already exists and is validated at scale (227 cards); we have an empty `lab/experiments/` waiting for `E-M9` |
| VecDHT → here | **M2** metrics with commands | we already cite numbers (`recall 0.71`, `coverage 0.79`) that no one can re-shoot — this is the fix |
| VecDHT → here | **M5** status doc | without it, "done" means whatever the last commit message says |
| here → VecDHT | **M3** claim registry | their results are stated in prose; a typed registry would attach the strongest permitted wording to each |
| here → VecDHT | **M6** full guard set | they have secret scanning; link and claim checks are small additions |

M4 and M7 stay ours to finish first: neither repository has a recorded independent-rebuild test, which is the
external node both loops depend on.

## Gaps on our side, named plainly

1. `lab/experiments/` does not exist. `E-M9` (the substitution test) is the first card, and until it exists the
   kit's M1 cannot be claimed at all.
2. No metrics document. Every number in this repository is currently a citation, not a measurement.
3. No status document. The repository has a plan and a specification, and no falsifiable statement of what works.
4. M7 detection in the checker was matching prose that *described* an independent rebuild. Tightened in this
   pass: it now requires a recorded result. That is a defect in the instrument, found by running it on ourselves.

## Decisions

- **No ADR.** No drift was found, and prose is not a fix for a gap that has a name (`E-M9`).
- **Structural churn tolerance confirmed in practice.** The checker found VecDHT's artefacts without knowing its
  paths, and will keep finding them when the restructuring lands.
- **Next pass:** after `E-M9` closes, because that is the first item that moves either column.
